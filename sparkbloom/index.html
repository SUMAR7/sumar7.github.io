    How messages work

    • Not private. Your words and name are written into the link. They are not encrypted, so never put secrets, passwords or personal details in a message.
    • Anyone with the link can read it, and can send it on to other people.
    • We never see it. Sparkbloom has no message server, so we can't read, check, track or delete a message.
    • It can't be taken back. A link stays in chats and browser history after you send it. A video shows the message too.
    • Names aren't checked. Anyone can type any name, so a name doesn't prove who wrote it.
